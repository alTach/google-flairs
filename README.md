# [Google Calendar Flairs](https://altach.github.io/google-flairs)
This service helps you understand which special word should be written in a Google Calendar event title so a beautiful themed picture appears for that event.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Production files are generated in `dist/`.
